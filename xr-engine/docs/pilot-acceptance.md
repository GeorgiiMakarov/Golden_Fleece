# Pilot Acceptance: «одна идеальная связка»

Критерий приёмки пилота контентной платформы на флоте QAZBOT.

## Конфигурация стенда

- 1 робот A2, sidecar-агент по `docs/integration-contract-sidecar.md`;
- референсный пак «Ару» (`examples/sample_character_pack.json`, delivery_tier L1);
- живые события Genie Studio Agent (имена `genie.*` — предварительные, до подтверждения каталога QAZBOT).

## Сценарий

| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Человек подходит к роботу | Датчик присутствия фиксирует зрителя |
| 2 | `genie.visitor_detected` | Пак переходит в `greeting`: синхронные голос + экран + жест |
| 3 | Реплика отыграна | Sidecar отправляет телеметрический лог с подписью ed25519 в аудит-панель |
| 4 | Проверка в панели | Видны событие, пак `pack_aru_guide`, длительность, подпись валидна |

## Критерий успеха

Связка 1–4 воспроизводится end-to-end на живых событиях **без ручных подпорок**: без ручного переключения состояний и без подмены логов.

## Вне скоупа пилота

L2 (XR-очки), распознавание лиц, аппаратные подписи (TPM/TEE) — v2.
