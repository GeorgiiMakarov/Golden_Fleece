# Integration Contract: тонкий sidecar-агент

Как подключить платформу к роботу, не залезая в его бортовой компьютер и не трогая управление.

## 1. Принцип

Мы не поставляем рантайм внутрь робота. Интеграция — один sidecar-процесс рядом с роботом (на бортовом companion-компьютере или на edge-хосте флота), который:

1. **читает** события Genie Studio Agent (read-only, TCP/WebSocket);
2. раз в N минут сверяет локальную библиотеку Character Pack с центральной;
3. **отправляет** подписанные телеметрические логи в аудит-панель.

Направление данных — строго наружу от робота. Sidecar ничего не пишет в контур управления, навигацию и safety.

## 2. Поток данных

```
Genie Studio Agent (события, read-only)
        │  genie.visitor_detected, genie.idle, ...
        ▼
sidecar: резолвит состояние пака → триггерит показ
        │  состояние → экран робота / голос (TTS) / жест (их AI-слой)
        ▼
sidecar: собирает телеметрию (event_id, timestamp, GPS, presence_hash)
        │  подписывает ключом ed25519
        ▼
аудит-панель (Showtime Audit / Defense-Dossier)
```

Датчик присутствия (лидар/ультразвук) подтверждает зрителя: «показ» засчитывается только при подтверждённом присутствии. Распознавание лиц не используется.

## 3. Лимиты ресурсов

Жёсткий лимит sidecar: **<5% CPU, <200 MB RAM**. Он не должен влиять на навигацию и safety-контуры робота. Как ограничить — на усмотрение интегратора (`systemd` cgroups, Docker `--cpus`/`--memory`): мы не требуем root и не диктуем упаковку.

## 4. Конфигурация

Весь контракт — один YAML: `examples/sidecar-config.yaml` (10 строк). Ключ подписи — ed25519, генерирует и хранит интегратор; платформа проверяет только подписи.

## 5. Что пишет интегратор

Ничего, кроме запуска sidecar с этим конфигом и проброса трёх endpoint'ов: поток событий Genie, датчик присутствия, HTTPS до аудит-панели. Имена событий `genie.*` — предварительные, до подтверждения каталога QAZBOT.

## 6. Честные границы

- Sidecar не делает AEC/VAD — это аудиостек робота.
- Sidecar не пишет кинематику — триггеры движений маппятся их motion-движком.
- Подпись телеметрии в v1 — софтверная (ed25519); аппаратный TPM/TEE — v2, на стороне производителя.
